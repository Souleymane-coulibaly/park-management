# Anomalies historiques — réexamen du Sprint 11B

Règle suivie : aucune anomalie n'est déclarée résolue sans preuve. « Non vérifiable ici » signifie
qu'aucun moyen de preuve n'existe dans cet environnement (matériel absent, base `test`
inaccessible).

Procédure : un seul processus Playwright, jamais `next build` à côté de `next dev`. Preuve hors ligne : le paramètre est bien enregistré (`pg_db_role_setting`) sur une base PostgreSQL jetable après migration. | La fermeture effective d'une session réelle reste à observer sur Neon `test` |
