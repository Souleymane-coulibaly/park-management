# Guide : votre site vitrine Ocall Park

Votre site présente votre établissement sur Internet : photos, horaires, adresse, téléphone,
WhatsApp, services, menu ou tarifs. Les prix affichés sont **indicatifs**. Le site ne vend rien, ne
prend ni réservation, ni commande, ni paiement.

Qui peut faire quoi :

- le **propriétaire** et l'**administrateur** modifient et publient le site ;
- seul le **propriétaire** gère le nom de domaine.

## 1. Créer le site

Menu **Site web** → choisissez l'établissement → indiquez l'adresse du site (ex. `maquis-le-baobab`)
→ **Créer le site**.

Le site est créé en **brouillon** : personne ne le voit tant que vous ne l'avez pas publié.

## 2. Remplir le contenu

- **Contenu** :
  - nom public, accroche, description ;
  - adresse et coordonnées GPS (pour le lien « Itinéraire ») ;
  - téléphone, WhatsApp, e-mail, réseaux sociaux (adresses `https://`) ;
  - horaires, services (un par ligne) ;
  - pour un parc : attractions et informations de sécurité.
- **Photos** : JPEG, PNG ou WebP, 5 Mo au plus. Choisissez un logo, une couverture et la galerie.
  Ajoutez une courte description de chaque photo, pour les personnes malvoyantes.
- **Menu et tarifs** : **rien n'est publié par défaut**. Cochez les plats et les tarifs d'entrée à
  afficher. Le prix indicatif est facultatif ; à défaut, c'est le prix de vente actuel. Vos coûts,
  stocks et marges ne sont jamais publiés.
- **Apparence** : thème, couleur principale (elle doit rester lisible avec un texte blanc), ordre des
  sections, sections masquées.

Cliquez sur **Enregistrer le brouillon** : vos changements restent invisibles du public.

## 3. Prévisualiser et publier

- **Prévisualiser** affiche le site tel qu'il sera, avec un bandeau « Aperçu ».
- **Publier** met le site en ligne. Il est ensuite affiché à son adresse publique, indiquée en haut
  de l'éditeur.
- Après une publication, vos nouvelles modifications restent en brouillon jusqu'à la publication
  suivante (badge « Modifications non publiées »).
- **Dépublier** retire le site d'Internet. Rien n'est effacé : vous pouvez le republier.

## 4. Utiliser votre propre nom de domaine (facultatif)

1. Onglet **Nom de domaine** : saisissez par exemple `www.monrestaurant.ml`.
2. Chez votre fournisseur de domaine, créez les deux enregistrements affichés : **TXT** (preuve de
   propriété) et **CNAME**.
3. Cliquez sur **Vérifier la propriété**. La propagation DNS peut prendre jusqu'à 72 h : réessayez
   plus tard si besoin.
4. Une fois la propriété vérifiée, l'équipe Ocall active le domaine et son certificat HTTPS. Votre
   site reste accessible à son adresse Ocall en attendant.

## 5. Abonnement

Si l'abonnement expire ou si le compte est suspendu, le site affiche « momentanément indisponible ».
Votre contenu est conservé et réapparaît dès la réactivation.
